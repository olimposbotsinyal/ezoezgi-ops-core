## v0.4.1-av-features-complete — `ad75d0f` (2026-08-14)

B038'in geri kalan iki "kapsam dışı" maddesi kapatıldı — Ops Suite'in
görsel/işitsel etkileşim hattındaki son iki iş:

- **B048 tamamlandı — çoklu-adımlı görev yaşam döngüsü animasyonu**
  (`kuyrukta -> atandı -> çalışıyor -> tamamlandı`): tamamen zaten var
  olan `task.lifecycle`/`agent.presence` WS olaylarına sürülüyor,
  backend'e HİÇBİR dokunuş yok. Dürüstlük notu (bkz. ADR-023):
  "tamamlandı" etiketi GÖREVİN BAŞARILI olduğu anlamına GELMEZ —
  yalnızca ajanın işlemeyi bitirdiği anlamına gelir; başarısız/reddedilen/
  onay-bekleyen görevler de working→idle çevrimi koşulsuz olduğu için
  AYNI görsel aşamaya ulaşır.
- **B050 tamamlandı — yerel ses ipucu çerçevesi** (global mute +
  politika kapısı, offline-first): Web Audio API ile sentezlenmiş
  tonlar, CDN/binary ses dosyası YOK. 3 ayırt edilebilir ipucu GERÇEK,
  ayrı koşullara bağlı (bkz. ADR-024): `approval_needed` (yeni onay
  kaydı), `task_complete` (başarıyla tamamlanan görev), `policy_block`
  (B044'ün gerçek 401/403 owner-root-guard reddi — fabrike bir 3.
  backend durumu icat edilmedi).

### Teknik özet
- Frontend/Canvas2D üzerinde lifecycle animasyon akışı gerçek event
  akışına bağlandı (`scene.js::applyTaskLifecycleEvent`).
- Ses tetikleyicileri yerel Web Audio API üzerinden çalışacak şekilde
  eklendi (`sound_cues.js`).
- Policy/mute kontrolleri ile ses davranışı yönetilebilir hale
  getirildi (gerçek bir mute düğmesi + `localStorage` kalıcılığı).
- Backend tarafında fonksiyonel değişiklik YAPILMADI (frontend odaklı
  sürüm) — pytest 953/953 bu yüzden değişmeden kaldı, yeniden
  çalıştırılarak doğrulandı.

### Test ve doğrulama
- **Playwright:** 21/21 PASS (12 mevcut + 2 yeni B048 + 7 yeni B050),
  ardışık 2 tam koşumla doğrulandı.
- **pytest:** 953/953 PASS.
- Deterministik test yaklaşımı korundu — sleep tabanlı flaky
  desenlerden kaçınıldı (gerçek WS frame yakalaması, T38 ile AYNI
  yöntem).
- Süreçte gerçek bir test hatası bulunup düzeltildi: aynı spec
  dosyasındaki iki test aynı paylaşılan sunucuya irreversible komut
  gönderince onay kuyruğu sayısı birikti — sabit sayı yerine
  önce/sonra farkı + `.last()` ile düzeltildi.

### Bilinen sınırlamalar
- **Sesin insan kulağıyla GERÇEKTEN duyulduğu doğrulaması:**
  `NOT_COLLECTED` — bu ortamda fiziksel ses donanımı (hoparlör) yok.
  Test edilen: doğru koşullarda doğru parametrelerle GERÇEK bir Web
  Audio API (`OscillatorNode`) çağrısının yapılıp YAPILMADIĞI.
  `heartbeat_tracker` DI edilmeden bir `create_app()` çağrılırsa
  (gerçek üretim yapılandırmasında olmaz) görev işaretçisi "atandı"
  aşamasında sıkışır.
- Politika kapısı (policy gate) şu an sabit/yerel seviyede
  (`policyEnabled=true`, kod içi) — merkezi bir config kaynağından
  (ör. `/api/config`) beslenmiyor; bu ileri faz BACKLOG'unda
  (T47-T49/B051-B053 güvenlik sertleştirme hazırlığıyla birlikte
  değerlendirilebilir, ama doğrudan bağımlı değil).
